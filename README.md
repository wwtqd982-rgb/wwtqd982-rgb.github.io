# 補助金サーチ（自動更新の静的サイト）

デジタル庁「Jグランツ」の公開APIから**募集中の補助金**を毎日自動取得し、
締切順・金額順・地域別・目的別に探せる静的サイトを生成します。

- **費用**：0円（サーバー代・API利用料ともに無料。独自ドメインだけ任意で年1,500円ほど）
- **必要な追加インストール**：なし（Python標準ライブラリのみ）
- **運用の手間**：公開後は自動。GitHubが毎朝6時に更新してくれます

---

## 構成

| ファイル | 役割 |
|---|---|
| `fetch_data.py` | Jグランツ APIから取得 → `data/subsidies.json` |
| `build_site.py` | JSON → `public/` に静的HTMLを生成 |
| `slugs.py` | URL用のスラッグ対応表 |
| `.github/workflows/update.yml` | 毎日の自動取得・自動公開 |
| `data/cache/` | 詳細APIの取得結果キャッシュ（差分取得用。消さないこと） |

詳細APIは1件1.7MBと重いため、一度取得したものはキャッシュし、
2日目以降は**新しく増えた補助金だけ**を取りに行きます。

## 手元で動かす

```bash
python fetch_data.py
```

```bash
python build_site.py
```

```bash
python -m http.server 8765 --bind 127.0.0.1 -d public
```

ブラウザで <http://127.0.0.1:8765> を開くと確認できます。

## 公開の手順（初回だけ／30〜40分）

### 1. GitHubにアップする

1. <https://github.com> で無料アカウントを作る
2. 右上の「+」→「New repository」。**Public** を選ぶ
   （Publicだと GitHub Actions と Pages が無料で使えます）

> ⚠ **リポジトリ名は `<あなたのGitHub ID>.github.io` にしてください。**
> 例: ID が `taro-example` なら `taro-example.github.io`。
>
> 生成されるHTMLのリンクは全て `/` 起点の絶対パスなので、**サイトはドメイン直下に
> 置く必要があります。** `subsidy-search` のような普通の名前にすると
> `https://taro-example.github.io/subsidy-search/` というサブディレクトリ配信になり、
> **全ページのリンクが404になります。**
> （`build_site.py` の `resolve_site_url()` がこの2種類を自動判別します）

3. 手元のフォルダで、以下を順に実行

```bash
git init -b main && git add . && git commit -m "初回"
```

```bash
git remote add origin https://github.com/あなたのID/あなたのID.github.io.git && git push -u origin main
```

GitHub Desktop を使っている場合は、「Add existing repository」でこのフォルダを追加してから
「Publish repository」を押すほうが簡単です（リポジトリ作成・認証・push が一度に済みます）。

### 2. GitHub Pages を有効にする

リポジトリの **Settings → Pages → Build and deployment → Source** を
**「GitHub Actions」** に変更する。これだけで `https://あなたのID.github.io/` に公開されます。

### 3. 運営者情報を入れる

`SITE_URL` は GitHub Actions 上で自動判別されるので**書き換え不要**です。
`build_site.py` の先頭にある次の2つだけを埋めて、もう一度 push します。

```python
OPERATOR = "サイト運営名（ハンドルネームで可）"
CONTACT  = "連絡用のメールアドレス"
```

> 連絡先には**普段使いのメールアドレスを載せないでください。** 公開ページに書いたアドレスは
> 収集ボットの対象になります。問い合わせ専用に無料のアドレスを1つ作るのが安全です。

> **独自ドメインを推奨**：`◯◯.com` などを年1,000〜1,500円で取得して
> Settings → Pages → Custom domain に設定すると、検索評価も広告審査も通りやすくなります。

### 4. Google に登録する

1. [Google Search Console](https://search.google.com/search-console) にサイトを登録
2. 「サイトマップ」に `sitemap.xml` を送信
3. 反映まで数日〜数週間かかります

## 収益化の順番

**焦って広告を貼らないこと。** 中身が薄いうちに申請すると審査に落ちて、再申請が面倒になります。

### 第1段階：アクセスを集める（0〜6ヶ月）

- Search Console で「どんな検索語で来ているか」を毎月見る
- よく検索されている補助金は、個別の解説を手で書き足す（ここが差別化になります）
- 「締切が近い補助金」ページを軸に、SNSで週1回だけ告知する

### 第2段階：アフィリエイト（月1,000PVあたりから）

審査がゆるく、補助金と相性がいいものから始めます。

| ASP | 相性のいい案件 |
|---|---|
| [もしもアフィリエイト](https://af.moshimo.com/) | 会計ソフト、法人向けサービス |
| [A8.net](https://www.a8.net/) | 会計freee、マネーフォワード、税理士紹介 |
| [バリューコマース](https://www.valuecommerce.ne.jp/) | ビジネス系全般 |

補助金を探している人は「これから設備やITに投資する事業者」なので、
会計ソフト・請求書ソフト・法人カードなどは相性が良く、単価も高め（1件3,000〜10,000円）です。

### 第3段階：Google AdSense（記事が増えてから）

- 申請の前提：独自ドメイン、`about.html` の運営者情報とプライバシーポリシー、
  **自動生成でない手書きのコンテンツが複数ある**こと
- 通過したら `build_site.py` の `ADSENSE_CLIENT` にIDを入れる。
  広告枠は `<div class="ad">` として各ページに用意済みです

### 第4段階：有料メール通知（本命）

「自分の地域・業種の新着補助金だけ毎週メールで届く」を月500〜1,000円で提供する。
データはすでに手元にあるので、あとは配信の仕組みだけです。
**ここまで来たら声をかけてください。実装します。**

## 法律・規約まわり（守るべきこと）

- **出典表示**：政府標準利用規約（第2.0版・CC BY互換）に基づき、出典を明記すれば商用利用可。
  フッターと `about.html` に記載済みです。**消さないでください**
- **免責表示**：自動取得データなので正確性を保証しない旨を明記済み
- **公式へのリンク**：各ページに公式ページへのリンクを設置済み（一次情報への導線）
- **申請代行はしない**：行政書士法との関係があるため、情報提供に徹すること
- **広告の明示**：アフィリエイトを貼る場合は「広告」「PR」と明記（ステマ規制／景品表示法）
- **確定申告**：給与以外の所得が年20万円を超えたら必要
- **有料サービスを始めるとき**：特定商取引法に基づく表記が必須

## 掲載件数を増やしたいとき

現在は**募集中のみ**を対象にしているため320件前後です。
`fetch_data.py` の `KEYWORDS` に業種・分野の言葉を足すと取りこぼしが減ります。
受付終了分をアーカイブとして残す方法もありますが、
中身の薄いページが増えると検索評価が下がるので、慎重に。
